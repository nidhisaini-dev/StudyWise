# StudyWise Project Statement

## Problem Statement

Students often have difficulty deciding which subjects require more attention because academic performance, attendance, assessment workload, and available study time are considered separately.

StudyWise addresses this problem by analyzing these academic factors together and generating a prioritized weekly study plan. The system helps students identify subjects that require greater attention and allocate their available study hours accordingly.

## Scope of the Project

StudyWise is a Python-based academic planning system designed for students.

The system covers:

- Student profile input
- Subject-wise marks analysis
- Attendance risk analysis
- Assessment workload tracking
- Subject priority calculation
- Weekly study-hour allocation
- Input validation and error handling
- JSON-based data storage
- Academic report generation

The current version is a console-based application and focuses on academic planning using rule-based calculations.

## Target Users

The primary target users are:

- College students
- Students who want to organize their weekly study time
- Students who need help identifying subjects requiring more attention
